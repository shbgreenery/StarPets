# 成长伙伴 · StarPets 🐾

> **📌 项目来源**：本项目改编自 [prompteric/class-pet-garden](https://github.com/prompteric/class-pet-garden)。原项目为 Vue3 + Node.js + SQLite 前后端分离架构；本项目已改造为**纯前端应用**（IndexedDB + Dexie），无需后端，可直接部署到 GitHub Pages。

> 家庭亲子激励工具，家长通过评价孩子表现给予星星，喂养宠物养成升级

![版本](https://img.shields.io/badge/version-1.1.1-blue)
![技术栈](https://img.shields.io/badge/技术栈-Vue3%20+%20IndexedDB%20(Dexie)-green)

## ✨ 项目简介

成长伙伴是一个面向家庭的亲子激励工具，将评价激励与电子宠物养成玩法相结合。家长（妈妈）在手机上操作，给每个孩子建立一只宠物，孩子表现好给**星星**，用星星喂养宠物、购买装扮。宠物有饥饿、清洁、快乐三项生存指标，需要持续照料；照料得当宠物成长升级，最终获得毕业徽章。游戏化的设计让家庭教育变得更有趣，激励孩子积极向上。

### 核心特点

- 👶 **宝贝管理** - 添加、删除宝贝（面向家庭多孩）
- 🐾 **宠物养成** - 26种可爱宠物，8级成长体系，每级形态变化
- 💖 **生存照料** - 饥饿值/清洁度/快乐指数三指标，每30分钟衰减，需要喂养维持
- ⭐ **星星激励** - 评价只给正分，按分值得星；星星用于商城购买补给
- 🛒 **宠物商城** - 内嵌详情面板，食物/用品/玩具消耗星星恢复指标
- 🍽️ **喂养动画** - 吃东西/洗澡/玩玩具时宠物卡片播放气泡台词+飘落动效
- 🎨 **装扮装饰** - 背景/挂饰/特效三类装扮，买一次永久拥有，可随时戴上/卸下
- 📈 **喂养成长** - 成长值由喂养驱动，不喂就不长；宠物会休眠，照料后恢复
- 🖱️ **宠物互动** - 点击宠物弹跳+气泡台词，26种宠物各有专属叫声，20条随机互动台词
- 🏆 **光荣榜** - 日/周/月榜，多孩家庭自动排行（🥇🥈🥉）
- 🎮 **你说我猜** - 亲子互动游戏，妈妈看图描述孩子猜，猜对得星星
- 📋 **记录与图鉴** - 评价记录分页、宠物图鉴
- 💾 **数据本地化** - IndexedDB 浏览器本地存储，无需服务器
- 📱 **响应式设计** - 适配电脑、平板、手机

## 🚀 快速开始

### 在线演示
访问：https://shbgreenery.github.io/StarPets/

### 本地开发

```bash
# 克隆项目
git clone https://github.com/shbgreenery/StarPets.git
cd StarPets

# 安装依赖（项目使用 pnpm）
pnpm install

# 启动开发服务器（纯前端，无需后端）
pnpm dev
```

浏览器访问 http://localhost:3001/StarPets/

### 生产构建与部署

本项目为**纯前端应用**，数据存储在浏览器 IndexedDB 中，无需后端服务器。

```bash
# 本地构建
pnpm build         # 产出 dist/，含 vue-tsc 类型检查
pnpm preview       # 本地预览构建产物

# 运行测试
pnpm test:run      # vitest 单元测试
```

**部署到 GitHub Pages**：push 到 `main`/`master` 分支后，GitHub Actions 会自动构建并发布（见 `.github/workflows/deploy.yml`）。首次部署需在仓库 Settings → Pages 中将 Source 设为 **GitHub Actions**。

## 🎯 功能详解

### 一、宝贝与宠物

| 功能 | 说明 |
|------|------|
| 添加宝贝 | 输入姓名添加，支持删除 |
| 领养宠物 | 26种宠物可选，可自定义宠物名字、随时更换 |
| 成长体系 | 8 级，每级对应不同形态，Lv.8 毕业获得专属徽章 |

#### 宠物类型（26种）

**普通动物（19种）**：
- 🐕 犬类（7）：西高地、比熊、边牧、柴犬、金毛、萨摩耶、哈士奇
- 🐈 猫类（4）：虎斑猫、波斯猫、布偶猫、橘猫
- 🐇 兔类（2）：垂耳兔、安哥拉兔
- 🐹 啮齿类（2）：仓鼠、银狐仓鼠
- 🦆 其他（4）：柯尔鸭、羊驼、小熊猫、柯基

**神兽（7种）**：
- 白虎、独角兽、青龙、朱雀、多肉精灵、貔貅、狻猊

#### 成长体系

| 等级 | 所需成长值 | 阶段 |
|------|----------|------|
| Lv.1 | 0 | 初生 |
| Lv.2 | 40 | 成长 |
| Lv.3 | 100 | 优秀 |
| Lv.4 | 180 | 进阶 |
| Lv.5 | 280 | 稀有 |
| Lv.6 | 400 | 精英 |
| Lv.7 | 540 | 史诗 |
| Lv.8 | 700 | 传说（毕业）|

**毕业奖励**：宠物达到 Lv.8 获得专属徽章。

### 二、宠物状态与商城

每只宠物有三项**生存指标**（0-100，新宝贝初始 80）：

| 指标 | 图标 | 说明 |
|------|------|------|
| 饥饿值 | 🍗 | 随进食恢复 |
| 清洁度 | 🧼 | 随洗护恢复 |
| 快乐指数 | 🧸 | 随玩耍恢复 |

**衰减规则**：三项指标每 30 分钟各降低 1（直至 0）。

**两种状态**：
- 🟢 **成长状态** - 三项指标都 > 0，宠物正常成长
- 💤 **休眠状态** - 任意一项指标为 0，宠物休眠；购买对应补给恢复后自动解除

**宠物商城**（内嵌于宝贝详情面板的「商城」tab，消耗星星购买，指标 +15/+30，上限 100）：

| 商品 | 图标 | 目标 | 加值 | 价格 |
|------|------|------|------|------|
| 烤鸡腿 / 红苹果 | 🍖/🍎 | 饥饿值 | +30 / +15 | 10星 / 5星 |
| 沐浴露 / 香毛巾 | 🧼/🧻 | 清洁度 | +30 / +15 | 10星 / 5星 |
| 布偶熊 / 小皮球 | 🧸/⚽ | 快乐指数 | +30 / +15 | 10星 / 5星 |

**喂养过程动画**：购买补给后关闭详情面板，对应宝贝卡片播放专属动画——吃东西「啊呜～🍖」、洗澡「洗香香～🫧」、玩玩具「好好玩～🧸」，配相关 emoji 飘落与宠物弹跳，2.5 秒自动消失。

**装扮装饰**：宝贝可用星星购买三类装扮，买过一次**永久拥有**，可随时「戴上 / 卸下」，只扣星星、不涨成长值：

| 类型 | 数量 | 槽位 | 说明 | 价格 |
|------|------|------|------|------|
| 🎨 装扮背景 | 5 | 单槽 | 宠物显示区渐变底色，宠物图四周留白相框 | 20~30 星 |
| 🎀 装扮挂饰 | 5 | 最多同时戴 3 个 | 宠物旁叠加的 emoji 小挂饰 | 5~20 星 |
| ✨ 装扮特效 | 5 | 单槽 | 宠物区粒子动画（下雪/星光/樱花/泡泡/萤火） | 45~55 星 |

- **拥有 ≠ 佩戴**：购买即自动戴上（单槽覆盖旧装扮）；卸下后拥有权保留，可免费再戴
- 装饰显示在首页卡片宠物区与详情面板头像区两处；挂饰最多同时佩戴 3 个

### 三、评价系统

评价采用**只加分、不扣分**的设计，宝贝通过表现获得**星星**，星星可用于商城。

#### 评价分类
- 📚 学习：作业、测验、考试相关
- 🎯 行为：纪律、礼仪、互助相关
- 💪 健康：卫生、值日相关
- 📝 其他：活动、比赛等其他项目

#### 默认规则（45条，全部为正分）

| 分类 | 条数 |
|------|------|
| 学习 | 9 |
| 行为 | 13 |
| 健康 | 7 |
| 其他 | 16 |
| **合计** | **45** |

#### 评价示例
- 作业完成优秀 +1
- 平时测验满分 +3
- 主动帮助同学 +2
- 拾金不昧（贵重物品）+5
- 区级及以上一等奖 +8

#### 自定义规则
- 输入名称 + 选择分类 + **五颗星星评分**（点亮几颗算几分，1-5 分）
- 所有规则都可以删除（包括默认规则）

### 四、成长值规则

- **评价只给星星**，不直接涨成长值
- **成长值由喂养驱动**：在商城购买补给喂养时增加，`成长值 += 物品加值 ÷ 5`（向下取整，如 +30 物品得 6 点，+15 得 3 点）
- **休眠状态不涨成长值**：任意指标为 0 时喂养只恢复指标、不加成长值；恢复成长状态后再喂养才涨
- 成长值不再随时间自动增长，宠物不喂就不长

### 五、宠物互动

点击宠物卡片上的宠物，它会弹跳并冒出气泡台词：

- **专属叫声** — 26 种宠物各有不同叫声（汪汪、喵喵、吱吱等）
- **随机互动** — 20 条互动台词随机出，如「你是要和我玩游戏吗？」「商城里有一个好看的发卡～」
- **动态调权** — 饥饿/清洁/快乐指标偏低时，相关台词出现概率提升 3 倍
- **小知识** — 部分宠物会分享趣味小知识（如「猫咪一天有 70% 的时间在睡觉」）

### 六、光荣榜

从「更多」菜单进入，按日/周/月统计所有孩子获得的星星：

| 孩子数量 | 显示 |
|:--------|:----|
| 1 个 | 不显示 |
| 2 个 | 仅 🥇 第一名 |
| ≥3 个 | 🥇🥈🥉 前三名 |

### 七、你说我猜亲子游戏

从「更多」菜单进入，妈妈和孩子一起玩：

1. 选择宝贝和分类（动物/食物/日常/认知/进阶）
2. 手机显示 emoji，妈妈描述，孩子猜
3. 猜对得 1 星，答错不扣星
4. 每轮 5 题，顶部 ✓/✕ 实时显示进度
5. 结束后显示成绩和题目回顾

### 八、图鉴与记录

- **宠物图鉴**：26 种宠物的 1-8 级形态预览，普通/神兽分类筛选
- **评价记录**：所有评价按时间倒序分页展示

## 🏗️ 技术架构

### 系统架构

```
┌─────────────────────────────────────────────┐
│                Vue 3 前端                   │
│                                             │
│   页面/组件  ←→  组合式函数  ←→  数据访问层  │
│                                  (src/db)   │
│                                    │        │
│                                    ▼        │
│                               Dexie         │
│                                    │        │
│                                    ▼        │
│                             IndexedDB       │
│                            (浏览器内嵌)      │
└─────────────────────────────────────────────┘
```

### 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | Vue 3 + TypeScript | 渐进式框架，类型安全 |
| 构建 | Vite | 快速构建工具 |
| 样式 | Tailwind CSS | 原子化CSS框架 |
| 数据层 | Dexie | IndexedDB 封装库 |
| 存储 | IndexedDB | 浏览器内嵌数据库 |
| 测试 | Vitest + fake-indexeddb | 数据层单元测试 |

### 数据访问层

数据访问逻辑集中在 `src/db/` 目录，通过 Dexie 封装 IndexedDB：

| 模块 | 职责 |
|------|------|
| `src/db/index.ts` | Dexie 实例、5 张表 schema（v1~v6 升级）、`initDb` 初始化 |
| `src/db/classes.ts` | 宝贝 CRUD、指标衰减、成长值（喂养驱动）、商城购买、毕业徽章 |
| `src/db/evaluations.ts` | 评价记录 + 星星联动 |
| `src/db/rules.ts` | 评价规则 + 设置 |

### 数据表结构（IndexedDB / Dexie）

| 表 | 主键 | 索引字段 | 说明 |
|----|------|---------|------|
| students | id | name, total_points | 宝贝（三指标/星星/等级/经验/装扮装饰） |
| badges | id | student_id, pet_type | 毕业徽章 |
| evaluation_rules | id | category, is_custom | 评价规则（正分） |
| evaluation_records | id | student_id, timestamp | 评价记录 |
| settings | key | — | 设置 |
