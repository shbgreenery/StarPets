一、产品背景与目标

1.1 要解决的问题

  • 家长难以持续、有趣地激励孩子完成日常任务（刷牙、收拾玩具、练琴等）。
  • 现有同类产品存在内购氪金、宠物死亡机制，给孩子带来金钱压力和心理负担。
  • 家长需要一个纯工具属性、无商业干扰的亲子互动介质。

1.2 产品目标

  • MVP阶段：验证“任务→星星→宠物养成”闭环的吸引力和留存率。
  • 增长阶段：通过口碑传播积累10万+家庭用户。
  • 长期愿景：成为国内家长首选的“零成本习惯养成工具”。

1.3 差异化卖点

维度竞品常见做法我们的做法
付费模式订阅/内购/会员完全免费，无任何金钱充值入口
宠物死亡可能饿死/病死，需氪金复活永不死亡，数值归零时进入“冬眠”，用任务星星购买道具唤醒
家长定位管理者/监督者裁判+讲解员，强调亲子共看共讲
商业变现向家长收费后续通过无干扰的电商场景推荐（CPS）变现

二、用户角色与场景

角色操作端核心行为典型场景
家长 手机（App/小程序） 创建任务、确认完成、打1-5星、购买道具、展示宠物、讲解故事 孩子练琴结束，家长拿出手机点击“完成”并打4星，举给孩子看宠物转圈吃蛋糕的动画
孩子 无操作端（纯线下观察与口述） 执行任务、观看宠物反馈、口述决策（起名、选宠物、选装饰） 坐在家长旁边，指着屏幕说“我要养这只小猫咪”，家长代为操作

三、功能需求详述

3.1 宠物领养与命名仪式（首次启动）

触发条件：用户首次打开App。

流程：

  1. 选择宠物：屏幕展示3只不同风格宠物（建议：小恐龙、小猫咪、小企鹅），孩子口述选择，家长点击确认。
  2. 命名仪式：弹出命名输入框，家长输入孩子口述的名字（如“小毛球”）。
    • 限制：2-6个中文字符。
    • 确认后弹窗：“【名字】将成为你独一无二的伙伴，确定吗？”（增加仪式感）
  3. 初始状态：宠物三维状态（饱腹/清洁/快乐）均从 50% 开始。
  4. 新手引导：自动弹出3步引导页，告诉家长如何创建任务、打星、购买道具。
🎯 交互要求：命名过程要缓慢且有仪式感，比如输入框带闪烁光标和星星飘落背景，给家长留足“念给孩子听”的时间。

3.2 任务系统（家长端）

入口：底部Tab栏“任务” > “今日任务”。

3.2.1 任务类型

类型说明示例
一次性任务单次有效，完成后不会重复出现“今天把玩具全部收进箱子”
每日任务每天自动重置出现“早晚刷牙”
每周任务选定周几重复出现“每周六整理书桌”

3.2.2 创建任务

点击“+”按钮，进入创建页：

字段必填说明
任务标题✅限20字，如“自己穿袜子”
任务描述❌选填，家长可记录具体要求，如“不要穿反了哦”
任务类型✅下拉选择：一次性/每日/每周
生效时间✅每日任务选时间（如每天19:00）；每周任务选周几
关联宠物❌默认奖励给当前选中的宠物，也可指定“喂给宠物1/2/3”

3.2.3 任务看板

  • 按日期分组展示“今日待办”。
  • 已完成任务显示为灰色对勾，并标注“+X星”。
  • 逾期未完成的任务（已过生效时间）显示橙色圆点提醒家长。

3.2.4 任务模板库（提高效率）

内置20个高频任务模板，支持一键添加：

分类模板示例
生活习惯早晚刷牙、自己穿衣服、按时睡觉、自己收拾书包
家务劳动收拾玩具、摆碗筷、叠被子、擦桌子
学习习惯练琴30分钟、阅读20分钟、完成作业、练字一页
品德习惯主动打招呼、分享玩具、不说脏话、帮助家人

交互：点击“从模板添加”，弹窗勾选所需任务，一键全部加入今日任务列表。

3.3 星级评价系统（核心交互）

触发：家长点击任务卡片上的“确认完成”按钮。

流程：

  1. 弹出5颗大星星（横向排布，按钮直径至少48px，适合家长手指点按）。
  2. 家长点击第N颗星，前N颗亮起（如点第4颗，亮4颗，第5颗灰暗）。
  3. 点击“确认发放”按钮，完成评价。

评级参考标准（在打星界面底部以小字展示）：

  • ⭐ 1星：勉强完成，需多次催促
  • ⭐⭐ 2星：按时完成，质量一般
  • ⭐⭐⭐ 3星：顺利完成，态度端正 （基准线）
  • ⭐⭐⭐⭐ 4星：完成得很好，超出预期
  • ⭐⭐⭐⭐⭐ 5星：表现惊艳，有明显进步

反馈：

  • 确认后，全屏播放3-5秒庆祝动画（如撒花/烟花/宠物转圈）。
  • 星星数量实时更新到总余额。
  • 若该任务关联了宠物，动画中宠物出现并做出高兴动作。

3.4 宠物系统（情感纽带）

入口：底部Tab栏“宠物” > 主展示页。

3.4.1 主展示页布局

+------------------------------------------+ | [←] 小毛球 Lv.5 ⭐⭐⭐⭐⭐ [→] | ← 顶部：宠物名 + 等级 + 切换箭头 | | | （宠物动态展示区） | ← 中间：宠物动画（趴/坐/跳/睡） | 🐱 （各种动作） | | | | 🍗 ████████░░ 80% 😊 饱饱 | ← 三维状态条（表情+进度条） | 🧼 ██████░░░░ 60% 😊 干净 | | 🎈 █████████░ 90% 😊 开心 | | | | ⭐ 当前星星：25颗 | ← 星星余额 | 🌱 成长值：30/100 (Lv.5 → Lv.6) | ← 经验进度条（重点突出） | | | [🏪 商店] [📋 任务] [📊 成长记录] | ← 底部操作按钮 +------------------------------------------+

3.4.2 多宠物管理（最多3只）

  • 切换方式：主展示页顶部左右箭头切换，或下拉菜单选择。
  • 适用场景：二胎家庭，或一个孩子想养多只不同宠物。
  • 任务关联：创建任务时可选择“将星星喂给哪只宠物”，支持单选或多选（多选时星星均分）。
  • 独立性：每只宠物的三维状态、成长值、等级、商店解锁进度完全独立。

3.4.3 宠物状态表现

三维数值变化时，宠物动画和表情同步变化：

状态区间表情/动画家长提示语参考
80%-100%😄 跳跳/转圈/冒音符“它今天好开心呀！”
50%-79%🙂 安静坐着“它今天还行，可以再吃点好的。”
30%-49%😕 耷拉耳朵/趴着“它有点饿了，我们赚星星给它买点吃的吧。”
1%-29%😢 头顶乌云/落寞“它好饿好难受，快救救它！”
0%（冻结/冬眠）😴 蜷缩睡觉，头顶Zzz“[名字]累坏了，正在睡大觉呢。攒3颗星买个醒醒果吧。”
💚 特别说明：宠物永远不会死亡。数值降到0%时自动进入“冬眠”状态，无任何负面惩罚，仅需用星星购买道具唤醒。

3.5 三维状态与成长值系统（核心算法）

3.5.1 三维状态（饱腹/清洁/快乐）

属性图标自然衰减速度衰减说明
饱腹度🍗每天 -15%每天凌晨0点结算时衰减
清洁度🧼每天 -10%每天凌晨0点结算时衰减
快乐度🎈每天 -12%每天凌晨0点结算时衰减

衰减下限为0%，不会为负。

3.5.2 成长值结算（每日凌晨0点自动执行）

系统根据当日三维状态的平均分，结算“成长值”（即经验值）：

当日平均分区间获得成长值家长端提示语（可念给孩子听）
≥ 80%（优秀照顾）+10“你把[宠物名]照顾得太好啦，它长高了一大截！”
50% - 79%（基础照顾）+5“今天喂得不错，明天记得给它洗个澡就更棒啦。”
< 50%（疏于照顾）+1（保底）“[宠物名]今天有点饿，明天我们多赚星星喂饱它吧。”
✅ 注意：绝不扣减成长值。最低也有+1保底，避免孩子因中断使用而产生挫败感。

3.5.3 等级与升级

  • 升级所需经验：【建议值】当前等级 × 20（Lv.1→Lv.2需20点，Lv.2→Lv.3需40点，以此类推）。
  • 升级反馈：达到升级所需经验时，全屏播放升级动画（约5秒，如宠物被光圈包裹、变大、闪亮），并弹窗提示：“[宠物名]升级啦！Lv.X → Lv.X+1，商店解锁了新物品！”

3.6 星星商店（货币消耗）

入口：宠物主展示页底部“商店”按钮。

3.6.1 消耗品类（提升三维数值）

类别道具示例功能建议售价
食物牛奶、小鱼干、水果拼盘饱腹度 +30%2 星
清洁小毛巾、泡泡浴液清洁度 +30%2 星
玩具毛线球、小皮球、积木快乐度 +30%3 星
豪华大餐（Lv.8解锁）三文鱼、大蛋糕饱腹度 +50%5 星
魔法醒醒果（特殊）魔法醒醒果将冬眠宠物唤醒，三维恢复至30%3 星

交互：点击道具 → 弹窗确认“确定要花X颗星购买吗？” → 确认后星星扣除 → 宠物播放使用动画（吃/洗/玩） → 对应数值条上涨动画。

3.6.2 限时装饰类（核心驱动力）

解锁等级装饰类型有效期建议售价举例
Lv.5初级头饰3天5 星小礼帽、蝴蝶结、墨镜
Lv.10中级套装5天15 星小西装、公主裙、超人披风
Lv.15动态背景永久30 星星空背景、花园背景、海底世界

装饰交互：

  • 购买后自动穿戴，宠物显示新形象。
  • 到期后装饰自动卸下，宠物显示失落小动画（如帽子飞走）。
  • 家长可随时在“已拥有”列表中查看所有装饰及其剩余有效期。

3.6.3 商店刷新策略

  • 每日特惠：每天随机1个消耗品打8折（如今天牛奶只需1星），页面顶部显示“今日特惠！”标签。
  • 限时绝版：节日（六一、国庆、新年）上架1款限定装饰，有效期仅7天兑换，过期下架。
⚠️ 重要原则：商店内没有任何用现实货币购买的入口。所有道具均用星星兑换。

3.7 宠物冻结/冬眠与唤醒机制（核心温情设计）

触发条件：任何一项三维状态数值降至 0% 时，宠物自动进入冬眠状态。

冬眠表现：

  • 宠物蜷缩在屏幕中央，头顶显示“Zzz”气泡。
  • 三维状态条全部清空，显示“💤 沉睡中”。
  • 页面提示语：“[宠物名]玩累了，正在呼呼大睡。攒够3颗星星，买一颗‘魔法醒醒果’就能叫醒它哦！”

唤醒流程：

  1. 家长点击“去商店”或“购买醒醒果”。
  2. 确认花3颗星星购买“魔法醒醒果”。
  3. 点击“使用”，播放唤醒动画（约5秒）：醒醒果飞入宠物嘴中 → 宠物打哈欠 → 伸懒腰 → 跳起来转圈。
  4. 宠物恢复至清醒状态，三维状态自动恢复至 30%（饱腹30/清洁30/快乐30）。
  5. 额外赠送一个“欢迎回来”小装饰（如一顶睡帽），有效期1天，增加仪式感。

防滥用与长停用处理：

  • 如果宠物连续冬眠 超过7天（家长确实很久未使用），系统不会删除任何数据。
  • 家长再次打开时，推送一条温馨提示：“[宠物名]等你很久啦，它好想你！攒点星星给它买个醒醒果吧。”
  • 不设任何惩罚性措施（如扣减成长值、删除装饰等）。

3.8 家长控制面板（后台）

入口：底部Tab栏“我的” > “家长设置”（需简单密码/PIN码验证）。

功能说明
多孩/多宠物管理开启/关闭“多宠物模式”（最多3只）；重置某只宠物的数据（需二次确认）
宠物改名允许重置宠物名字，需输入当前名字验证 + 二次确认（防止孩子误操作）

任务模板管理自定义添加/删除任务模板
每日结算时间默认凌晨0点，支持家长自定义（如晚上9点孩子睡觉时结算）
冬眠提示开关开启后，宠物进入冬眠时向家长手机推送一条本地通知
电商推荐开关家长可选择是否显示场景化商品推荐（默认开启，可关闭）

入口：宠物主展示页底部“成长记录”按钮。

模块内容

荣誉墙展示所有曾经获得过的限时装饰（含获得日期和有效期），已过期的显示灰色

交互：家长可点击任意日期查看当日详情，也可将页面截图保存到相册（用于打印或分享）。

四、非功能性需求

4.1 交互与设计原则

原则要求
大按钮所有可供点击的按钮直径 ≥ 44px，推荐 48px

无障碍支持系统字体放大功能

4.2 动画与视觉资源

类型数量规格说明
庆祝动画30+MP4/GIF，3-5秒完成任务打星后播放，如撒花/烟花/星星雨
宠物动作10套Lottie/MP4包括：高兴、吃东西、洗澡、玩玩具、升级、冬眠、唤醒等
装饰展示按需PNG序列帧或Lottie限时装饰穿戴在宠物身上的展示动画

4.3 平台与技术选型建议

阶段建议理由
MVP微信小程序获客成本低、无需下载、开发周期短

指标要求
首页加载≤ 1.5秒（4G网络）

数据同步每次打开App自动同步云端，网络差时本地缓存可用

五、运营与商业模式

5.1 商业化路径（纯免费，无内购）

当前阶段：完全免费，零广告。

后续阶段：接入场景化电商CPS推荐，方式如下：

推荐位置推荐内容触发时机示例
任务完成页底部与该任务相关的儿童用品完成任务打星后“收玩具”→推荐儿童收纳架
宠物商店页底部宠物周边或洗护用品进入商店时洗澡道具→推荐儿童沐浴露
等级解锁页底部适龄玩具/绘本宠物升级时Lv.5解锁头饰→推荐手工材料包

推荐原则：

  • 不弹窗、不插屏、不视频广告，仅以信息流卡片形式安静出现。
  • 每条推荐写明推荐理由（如“很多家长反馈这款计时器帮助孩子建立了时间观念”）。
  • 所有推荐均带 × 关闭按钮，一键关闭后不再重复出现。
  • 家长可在“设置”中一键关闭所有推荐。

严禁推荐的品类：游戏充值卡、电子设备、垃圾食品、任何与“用钱买星星”相关的虚拟商品。

5.2 用户增长策略

方式说明

八、风险与应对

风险应对策略
经济系统通胀（星星太多花不完）通过“每日特惠”、“限时绝版装饰”、“高级道具定价”消耗存量星星；衰减速度可后台动态调整
经济系统通缩（星星太少玩不下去）每日任务保底给1星，基础食物定价2星，保证做1天任务至少能买1个道具
家长长时间不用导致宠物数据落后不设惩罚，冬眠不扣成长值，回归后赠送小装饰鼓励，强调“随时回来都可以”
电商推荐影响体验默认开启但可一键关闭；推荐内容严格筛选；不弹窗不插屏
儿童误操作（如误删宠物数据）所有破坏性操作需家长PIN码验证 + 二次确认
