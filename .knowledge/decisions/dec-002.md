# 决策：换宠物保留等级

## 背景
原 `PUT /students/:id/pet` 接口在换宠物时把 `pet_level=1, pet_exp=0`，导致 3 级宠物换宠物后变 1 级，且 `pet_exp` 与 `total_points` 数据不一致。

## 决策
- 换宠物只更新 `pet_type` 和 `pet_name`，保留 `pet_level` / `pet_exp`。
- 移除换宠物时的「满级发毕业徽章」逻辑。

## 理由
- 毕业徽章已在评价升级满级时正确触发（`evaluations.js`），换宠物不该重复发。
- `pet_exp` 是 `total_points` 的镜像，绕过评价流程改它会破坏不变量。
- 统一语义：换宠物 = 换外观，成长数据（等级/经验/徽章）全保留。
