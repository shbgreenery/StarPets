# 决策：pet_name 存 NULL + 显示层 fallback

## 背景
宠物命名功能，名字选填。

## 决策
- `students.pet_name` 存 NULL 表示「未命名」。
- 显示时 `pet_name || 品种名` fallback（前端 `getPetType(pet_type).name`）。
- 不在数据库冗余存储品种名（品种名可通过 `pet_type` 查到）。

## 理由
- 避免冗余：品种名已由 `pet_type` 唯一确定。
- 品种名将来改动时，未命名宠物显示自动跟随。
- 改名是独立操作，不触发等级/经验重置。
