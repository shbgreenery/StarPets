# 宠物命名功能

## 背景
学生领养宠物时，顺便给宠物起一个名字。后续该学生的宠物都用这个名字。

## 验收标准
1. **领养时命名**：选择宠物类型后，可输入名字（选填），点「确认领养」完成领养。
2. **默认名**：名字留空时，显示层 fallback 到宠物品种名（如「西高地」「柴犬」）。
3. **改名**：详情面板展示宠物名字，并提供编辑入口随时改名。
4. **兼容旧数据**：已领养但未命名的宠物（`pet_name` 为空）正常显示品种名。
